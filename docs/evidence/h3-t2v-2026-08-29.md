## Quality Gate Follow-up

The original run used a legacy freeze gate that allowed up to 95% of the clip to be static, so the seed-42 sample was recorded as a hard-check pass. The production adapter now applies profile-specific freeze ratios: 30% for `baseline` and `audition`, and 20% for `final`. The observed 1.875 / 5.167 second interval is 36.3% and therefore fails the current audition gate. A synthetic regression with the same freeze duration verifies both rejection at 30% and passage at an explicitly lenient 40%; this corrects future admission decisions without rewriting the immutable historical sample.
